# GetJacked

A simple lift tracker that runs in your phone's browser.

- Log sets with weight and reps, with last session's numbers shown as you go
- Rest timer that starts when you check off a set
- Marks a lift to move up after 3 sets at the same weight
- Rate each workout and add a note
- Calendar of workouts, shaded by rating

Workouts are saved on the phone. Use **Settings → Backup** to save a copy.

Live at https://jackmogelof.github.io/getjacked/
